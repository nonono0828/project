# 项目合集

本仓库收录水凝胶机械手项目与智巡六足 AI 救援机器人项目。

| 项目 | 目录 | 内容与来源 |
| --- | --- | --- |
| 水凝胶机械手 | [水凝胶](水凝胶/) | 来自本机 `E:\hand_project\水凝胶`，包含 STM32 固件、电脑端源码、模型和技术文档 |
| 智巡六足 AI 救援机器人 | [六足救援机器人](六足救援机器人/) |  

水凝胶项目保留源码、依赖锁文件、烧录文件和模型。未收录 `node_modules`、电脑端重复构建目录、编译中间文件以及 `应用` 目录中的 Electron 打包程序；这些程序包含超过 GitHub 100 MiB 单文件限制的文件，可从源码重新构建。原始本地文件不受影响。

六足机器人以原仓库源码快照的形式放在独立子目录中，导入版本记录在该目录的 `IMPORT_SOURCE.md`。原作者的许可和版权声明保持原样；本合集未对原项目额外授权。
