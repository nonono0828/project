## 水凝胶机械手交互系统

系统将 3×3 水凝胶传感阵列的按压输入转换为手势指令，通过 STM32 固件采集信号，再由电脑端呈现三维机械手动作，适合柔性传感器、人机交互与手势可视化演示。

### 主要功能

- **阵列输入识别**：读取九个感知位置，结合启动校准、滤波和消抖处理稳定输入。
- **三维手势展示**：支持张开手掌、握拳、胜利手势、点赞、OK、食指指向、捏合、摇滚手势和自然放松九种姿态。
- **硬件串口连接**：桌面程序可枚举、连接和断开串口，以 115200 波特率接收设备数据。
- **无硬件模拟**：可通过界面按钮或键盘数字键 1–9 切换手势，方便独立演示。
- **动作参数调整**：提供拇指姿态校准、实时预览和参数保存。
- **桌面应用构建**：基于 Electron、Vite 和 Three.js，可构建 Windows 便携程序。

### 文件内容

## 智巡六足 AI 救援机器人

机器人面向建筑灾害、地下管廊、矿井、野外搜救与危险环境巡检，集成六足运动、端侧视觉、环境感知和物联网通信，提供现场侦察与远程协同能力。

### 主要功能

- **六足运动控制**：18 个舵机协同运动，支持基础步态、越野高抬腿和三档速度控制。
- **姿态稳定与避障**：使用 BMI088 获取姿态信息，结合 D6 360° 激光雷达完成距离分区、方向约束和自主脱困。
- **端侧人员检测**：独立 AI 视觉板识别人员并生成检测事件。
- **环境风险监测**：采集温度、湿度、气压、海拔和 MQ-2 可燃气体风险状态。
- **双源定位**：支持 GPS/北斗定位，并在无卫星定位时使用 L610 基站定位。
- **视频与数据回传**：ESP32-S3 负责摄像头采集、视频传输和现场配置，L610 Cat.1 与 Wi-Fi 提供通信链路。
- **远程管理**：网页端与手机端支持控制、视频查看、定位、传感器数据、事件和网络管理。
- **本地安全控制**：运动安全闭环保留在设备端，并提供控制超时保护与异常退化处理。
