# 水凝胶机械手

本项目将 3×3 水凝胶传感阵列的按压输入转换为手势指令，通过 STM32 采集与串口通信，在电脑端实时展示三维机械手动作，支持柔性传感器与人机交互演示。

## 主要功能

- 九个感知位置的输入识别，结合启动校准、滤波和消抖处理稳定信号。
- 三维机械手展示，支持张开手掌、握拳、胜利手势、点赞、OK、食指指向、捏合、摇滚手势和自然放松九种姿态。
- 硬件模式下枚举和连接串口，以 115200 波特率接收传感器数据。
- 模拟模式下通过界面按钮或键盘数字键 1–9 切换手势，无需连接传感器即可演示。
- 拇指姿态校准、实时预览与参数自动保存。
- 基于 Electron、Vite 和 Three.js 的桌面可视化应用，支持构建 Windows 便携程序。

## 项目文件

- `GESTURE_3X3_final/`：STM32 固件和 Keil 工程，保留已有的 HEX/BIN 烧录文件。
- `PC_APP/`：Electron/Vite 电脑端源码、依赖锁文件和测试。
- `robotic_hand.glb`、`robotic_hand2.glb`：机械手模型；电脑端使用的模型同时保留在 `PC_APP/public/models/`。
- `说明书.md`、`技术文档.docx`、`水凝胶密码锁方案.docx`：原始接线说明及技术文档。

## 从源码运行电脑端

安装兼容 Vite 7 的 Node.js 版本后，在 `PC_APP` 目录执行：

```powershell
npm ci
npm run dev
```

生成 Windows 便携程序：

```powershell
npm run dist:win
```

硬件接线见 `说明书.md`，传感器与系统设计见技术文档。桌面程序可从源码构建，串口连接功能需在 Electron 桌面环境中使用。
